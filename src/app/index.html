Built-in MCP server

Connect to Claude Code one time
claude mcp add shotik --transport http http://127.0.0.1:7464/mcp
After this, Claude can take screenshots of your screen by itself.
What Claude can do through Shotik
  • take_screenshot — look at the screen right now
  • ask_user_to_select_region — ask you to select an area
  • get_last_screenshot — grab your latest screenshot
  • take_screenshot_region · list_screenshots · list_displays
