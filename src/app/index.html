Подключение к Claude Code один раз
claude mcp add shotik --transport http http://127.0.0.1:7464/mcp
После этого Claude сможет сам делать скриншоты твоего экрана.
Что умеет Claude через Shotik
  • take_screenshot — посмотреть на экран прямо сейчас
  • ask_user_to_select_region — попросить тебя выделить область
  • get_last_screenshot — взять твой последний снимок
  • take_screenshot_region · list_screenshots · list_displays
💡 Скопированный снимок вставляется в Claude Code как картинка (Ctrl+V), а в обычный терминал — как путь к файлу. Это Smart Clipboard: оба формата кладутся в буфер сразу.
